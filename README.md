# 정훈봇

정훈봇은 참조 사진 두 장을 바탕으로 새 짤을 만들고, 사진 속 상황에 어울리는 짧은 대사를 디스코드에 함께 올리는 봇입니다. 서버별로 채널을 지정하면 한국 시간 기준 낮과 밤에 하루 한 번씩, 각 시간대 안에서 무작위 시각에 발송합니다. 모든 서버는 같은 예약 시각에 같은 사진과 대사를 받습니다.

## 하는 일

- `gpt-6-luna`가 상황·이미지 프롬프트·대사를 만들고 `gpt-image-2`가 사진을 생성합니다. 모델과 화질은 `.env`에서 바꿀 수 있습니다.
- 참조 사진은 비공개 `.env`의 `PHOTO_REFERENCES=첫사진.jpg,둘째사진.jpg`에 명시한 **두 장만 순서대로** 사용합니다. 첫 번째 사진을 얼굴의 주된 기준으로 사용하며, 설정이 없거나 파일이 없거나 장수가 맞지 않으면 생성 전에 오류를 냅니다. 사진 자체는 공개 저장소에 올리지 않습니다.
- 이세계 능력 각성, 최종보스, 초호화 무대, 코스프레, 과장된 리액션, 단체 난장판 등 14개 유형을 사용합니다. 최근 4개 유형을 피해서 비슷한 짤이 연달아 나오지 않게 합니다. 유형은 짧은 아이디어 씨앗으로만 쓰고 장면의 구체적인 연출은 모델에 맡깁니다.
- 하루 두 회차 중 한 회차는 날짜별로 고정되는 **레전드 짤 도전**입니다. 후보 장면 3개를 먼저 구상하고, 가장 강한 시각적 농담을 골라 순간·표정·구도·작은 보조 디테일까지 다듬습니다. 이미지 생성은 회차당 한 장이며, 웃음의 정도는 생성 결과에 따라 달라질 수 있습니다.
- 가끔 한국의 최근 트렌드에서 가벼운 밈 후보를 확인합니다. 적절한 소재가 없으면 일반 짤을 만듭니다.
- 사진에는 대사·자막을 넣지 않습니다. 대사는 디스코드 카드의 첫 줄에 표시합니다.
- 발송 시간대는 보이는 낮·밤 조명에만 반영합니다. 낮 발송이 식사 장면을 뜻하지는 않으며, 소재는 선택된 유형에 따라 달라집니다.
- 예약과 이미지 생성 결과는 모든 서버가 공유하는 SQLite DB에 저장합니다. 서버별로는 채널 설정과 게시 결과만 따로 기록합니다. 서버가 늘어도 자동 이미지 생성은 하루 두 장입니다.
- 유형과 별개로 카드 등급을 추첨합니다. 대사 → 사진 → 작은 등급 문구 순서의 카드로 게시하며, 등급에 따라 색상 막대·기호·문자 강조가 달라집니다. 같은 사진을 받는 모든 서버에는 같은 등급이 표시됩니다. 등급 문구의 이름은 비공개 `.env`의 `CARD_DISPLAY_NAME`으로 바꿀 수 있습니다.

## 짤 유형 분포

하루 두 장은 일반 짤 한 장과 레전드 짤 한 장입니다. `bot.py`의 `SCENARIO_WEIGHTS`로 유형별 상대 확률을 정하고, 레전드 짤은 `LEGEND_CATEGORIES`에서만 뽑습니다. 아래는 최근 유형 제외 **전**의 가중치 비율이며, 실제 선택 확률은 매번 달라집니다.

| 상황 묶음 | 일반 짤 | 레전드 짤 |
| --- | ---: | ---: |
| 이세계 각성·최종보스·초호화 무대 | 29/88 (약 33%) | 29/74 (약 39%) |
| 코스프레·단체 난장판·전설의 밤 | 19/88 (약 22%) | 19/74 (약 26%) |
| 표정·리액션·무표정 대참사·셀카 배경 | 26/88 (약 30%) | 26/74 (약 35%) |
| 공식 행사·역할 교체·현실 버그·유명인 투샷 | 14/88 (약 16%) | 0% |

레전드 회차는 후보 세 장면을 구상한 뒤 가장 재미있는 것을 고릅니다. 유형 분포나 카드 등급이 실제 이미지의 재미를 보장하지는 않습니다.

카드 등급은 유형과 독립적으로 정합니다. 일반 회차는 N 55%·R 35%·SR 9%·SSR 1%, 레전드 회차는 SR 80%·SSR 18%·UR 2%입니다. 등급이 높을수록 프롬프트에 요구하는 시각적 농담의 강도와 카드 연출이 커집니다. 같은 등급이라도 실제 이미지의 재미는 생성 결과에 따라 달라집니다.

## 디스코드 명령

서버 관리자 또는 `BOT_OPERATOR_IDS`에 등록된 사용자가 실행할 수 있는 슬래시 명령입니다. 관리자 외 사용자를 허용하려면 비공개 `.env`에 사용자 ID를 쉼표로 구분해 추가하세요. 공개 저장소에는 사용자 ID를 넣지 마세요.

| 명령 | 기능 |
| --- | --- |
| `/정훈봇 설정` | 업로드 채널을 고르고 자동 발송을 켜거나 끕니다. |
| `/정훈봇 상태` | 다음 예약 시각과 최근 발송 내역을 확인합니다. |
| `/정훈봇 미리보기` | 짤을 한 장 생성합니다. 유형·분위기·시간대·이슈 후보 확인 여부·일반/레전드 목표·카드 등급을 선택할 수 있고, 결과가 마음에 들면 버튼으로 채널에 게시할 수 있습니다. 등급을 비워두면 확률에 따라 추첨합니다. |

미리보기 생성에는 OpenAI API 비용이 듭니다. 게시 버튼은 한 번만 처리되며, 최근 미리보기는 봇 재시작 후에도 버튼 연결을 복구합니다.
참조 사진은 지정한 두 파일만 사용합니다. 이미지 API에는 얼굴이 크게 보이도록 중앙을 세로 비율로 자르고 긴 변을 최대 2048px로 줄인 RGB PNG 사본을 전달합니다. 원본 사진은 변경하지 않습니다.

## 빠른 시작: uv

Python 3.12와 [uv](https://docs.astral.sh/uv/)를 준비합니다.

```bash
uv sync --frozen
cp .env.example .env
# .env에 OPENAI_API_KEY, DISCORD_BOT_TOKEN, PHOTO_REFERENCES 입력
# photos/에 참조 사진 추가
uv run --frozen bot.py run
```

봇을 디스코드 서버에 `bot`과 `applications.commands` 범위로 설치하고, 사용할 채널에 채널 보기·메시지 보내기·파일 첨부 권한을 부여합니다. 서버 관리자 또는 허용 사용자가 `/정훈봇 설정`에서 채널을 선택해야 자동 발송이 시작됩니다.

기본 발송 구간은 `22:00–다음 날 04:00`, `11:30–13:30`(Asia/Seoul)입니다. `uv run --frozen bot.py plan`으로 등록된 서버의 예약과 레전드 회차를 확인할 수 있습니다. 사진만 만들려면 `uv run --frozen bot.py preview --slot dawn`을 사용합니다. 레전드 모드는 `--mode legend`, 특정 유형은 `--category fantasy_awakening`처럼 시험할 수 있습니다.

## Docker와 맥북 배포

`Dockerfile`과 `compose.yaml`이 준비돼 있습니다. 24시간 가동 맥북의 설정과 기존 DB 이전 절차는 [DEPLOY_MAC.md](DEPLOY_MAC.md)에 있습니다. 컨테이너는 `photos/`를 읽기 전용으로 사용하고 설정 DB·생성 이미지는 `data/`에 저장합니다.

Docker Desktop에서 새 컨테이너가 시작되지 않는 경우에는 [launchd 대체 실행 방법](DEPLOY_MAC.md#로컬-uv-실행)을 사용합니다.

```bash
mkdir -p photos data
docker compose up -d --build
docker compose logs --tail=50 bot
```

## 공개 저장소에 포함하지 않는 파일

`.env`, 참조 사진, 생성 이미지, 말투 참고 파일, 대화 원본, DB, 개인키는 `.gitignore`와 `.dockerignore`에서 제외합니다. `photos/`, `data/`, `persona.txt`의 내용은 Git을 통해 배포되지 않으므로 운영 기기에 별도로 옮겨야 합니다. 실제 인물 사진은 사용과 게시에 대한 동의를 받은 것을 사용하세요.

이미지 생성 품질과 인물 일치도는 장면에 따라 달라질 수 있습니다. 화질을 조정하기 전 `/정훈봇 미리보기`로 확인하세요. API 비용은 서버 수와 이미지 생성 횟수에 따라 달라집니다.
